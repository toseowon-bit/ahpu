- 자동 CI 설정 포함. GitHub Actions의 원격 실행 성공 여부는 별도 확인 필요.

## 브라우저 수동 확인 순서

1. 첫 화면의 예시 데이터 안내와 가상 제품 4개를 확인합니다.
2. `우리쌀` 검색은 다른 업체 제품 2개, 업체 `햇살` 필터는 1개여야 합니다.
3. 햇살식품 제품 상세에서 가상 회수 기록, LOT/기한 및 표시 원문을 확인합니다.
4. 관심 제품 등록 후 새로고침하고 관심 제품 탭에 남는지 확인한 뒤 해제합니다.
5. `두유` 상세는 동일 제품 미확정 후보만 표시해야 합니다.
6. `사과` 상세는 표시정보 미확인이며 무알레르기 판정을 표시하지 않아야 합니다.
7. 회수·판매중지 탭의 가상 사건 2개 및 없는 검색어의 빈 결과를 확인합니다.
8. 좁은 화면에서 가로 잘림과 키보드 포커스를 확인합니다.
9. 브라우저 저장 차단 시 저장 실패 안내를 확인합니다.
